# VÉRANE 2.0 regression checklist

- [ ] About, Contact and FAQ render for logged-out visitors.
- [ ] Admin can edit public content and see changes without deployment.
- [ ] Site settings, contact/social links, announcement, navigation and footer update correctly.
- [ ] Invalid JSON, invalid email and unsafe social URLs are rejected.
- [ ] Both brands remain separated in storefront and admin.
- [ ] Checkout, payments, per-brand fulfilment, receipts, inventory and back-in-stock remain functional.
- [ ] Campaign attribution and collaboration/scheduled visibility remain functional.
- [ ] Brand-scoped admins cannot edit global site content.
- [ ] Analytics obey brand scope; compare daily sales/category values with source orders.
- [ ] npm run typecheck, lint, test and build pass before merge.
- [ ] Do not deploy until separately authorized.
